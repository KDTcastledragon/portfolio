CastleChat Architecture

→ Grafana 시각화

Web Server NginX Reverse Proxy
Load Balancing
Process Domain Service 회원가입/로그인 · Snapshot Query · File Upload
Process WebSocket Gateway WsSession 관리 · 채팅방 입장/퇴장
Process AI Assistant Service 채팅방/상대에 맞는 메시지 추천받기
Process Channel Engine 실시간 채팅방 FEED/메시지/친구 관계 관리
Event Log Kafka durable ACK · retry · DLT
Process Event Persist Worker idempotent message DB write
Database Redis 채팅방멤버 및 채팅읽음 캐싱처리 · Dirty Flush
External API Gemini API LLM message recommendation
Database MariaDB domain · room · message persistence
  1. Entry

    Client ↔ NginX

  2. REST Domain Flow

    Nginx → Domain Service ↔ MariaDB
    Domain Service ↔ Redis Shared Session

  3. Realtime Message Flow

    Nginx ↔ WebSocket Gateway ↔ gRPC ↔ Channel Engine
    Channel Engine → Kafka → Event Persist Worker → MariaDB

  4. Realtime State

    Channel Engine ↔ Redis
    Channel Engine ↔ MariaDB

  5. AI Assist Flow

    Nginx → AI Assistant Service ↔ MariaDB Read Only
    AI Assistant Service → Gemini API
